# Project VeeTech

VeeTech Automation FZE — Premium Modern Website Redesign

Redesign and rebuild the complete website for VeeTech Automation FZE, a UAE-based industrial automation and energy-sector engineering company.

Reference website:
https://veetech.ae/

Use the existing website and its available content as the primary source of truth. Do not invent company facts, certifications, clients, project numbers, technical specifications, or capabilities that are not present in the source content.

The goal is NOT to make a generic corporate website.

Create a premium, modern, engineering-focused B2B website suitable for a UAE / Middle East Oil & Gas / Energy company.

The final result should look like a company that handles major industrial projects, engineering contracts and international energy-sector clients.
